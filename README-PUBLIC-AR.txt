5G Training — Public PWA v3.3.0

هذه النسخة لا تحتاج Google Apps Script أو Backend أو تسجيل دخول.

التشغيل:
1) ارفع محتويات هذا المجلد كما هي إلى Cloudflare Pages.
2) يجب أن يكون index.html في جذر النشر.
3) افتح الرابط وتأكد من ظهور الكورسين مباشرة.
4) جرّب فتح تمرين وصورة ورابط YouTube.
5) ثبّت PWA على الهاتف وجرّب إعادة فتحه.

السلوك الحالي:
- الكورسات والتمارين مخزنة محلياً في src/js/courses-data.js
- التقدم في التمارين يُحفظ محلياً على جهاز المستخدم.
- روابط YouTube تحتاج إنترنت.
- لا يوجد Users / Phone / PIN / Sessions / Permissions.

ملاحظة مستقبلية:
يمكن إضافة Login وBackend لاحقاً بدون الحاجة لإرجاع Google Apps Script؛ يفضّل وقتها إضافة طبقة API مستقلة مع إبقاء واجهة الكورسات منفصلة.
